    mock data (e.g. the ROWS array in 03-dashboard.jsx) — there is no real
    backend wired up yet. Implement all tasks below the same way: local
    component state / mock arrays, not real API calls. Follow the existing
    patterns (e.g. DemoStateSwitcher for toggling between states on a page)
